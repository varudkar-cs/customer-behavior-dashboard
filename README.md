# Customer Behavior Dashboard
## Objective
Analyze customer purchasing behavior and identify high-value segments.

## Overview 
    An Excel-based dashboard analyzing customer purchasing patterns and identifying high-value segments.
  
## Dataset
E-commerce customer transaction data including product categories and revenue.

## Key Insights
- Fragrance category generates the highest revenue, indicating strong demand for premium products.
- Customer C002 contributes the highest revenue, identifying a high-value repeat customer segment.
\
## Tools Used\
- Microsoft Excel (Pivot Tables, Charts)\
\
## Outcome\
Built a clean and structured dashboard to visualize customer trends and business insights.}
